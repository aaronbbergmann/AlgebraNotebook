# Migration step 1: everything saved first (2026-11-26)

The Question Bank migration (plan: "Algebra Notebook: Question Bank Restructure Plan") starts here. Step 7 checks the new system against these backups, and passes only at zero differences.

## In this folder (no student data: the repository is public)

- `activities.json`: every activity as it stood before the migration. For each of the 30 activities: abbreviation, title, section, exercises in order (62 in all), each exercise's modes and progress levels (Write rounds included), plus the reviews (RevT1, RevQ2) and their items, the Playgrounds, the copy groups (COPYG), the Chapter 3 solver map (C3SV) and the due dates (from the Progress Sheet's Settings tab).

## In Google Drive (student data stays there)

- A dated copy of the Progress Sheet, made by hand: open "Algebra Notebook Progress", choose File > Make a copy, and name it "Algebra Notebook Progress, backup 2026-11-26 (before Question Bank migration)". Its Students and Data tabs hold every student's saved progress (every activity's exercise and mode levels, stars, late marks); its Settings tab holds the due dates and classes.

Do not edit either backup. Step 7 reads them.
